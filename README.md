# Top Low-Code Application Platform (LCAP) Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Visual App Builders, Enterprise Low-Code Platforms & Self-Hosted Development Environments*  
**Last updated: October 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Low-Code Application Platforms (LCAP)**. These tools enable developers and citizen developers to visually build, deploy, and maintain business applications—from internal tools and admin panels to customer-facing portals—with minimal hand-written code while preserving extensibility, governance, and deployment control.

**Examples** include ServiceNow Low-Code App Engine, OutSystems, Mendix, Microsoft Power Apps, Appian, Quickbase, Retool, Zoho Creator, Caspio, and Bubble (the category leaders).

**Open-source emphasis**: This section is expanded with active projects for self-hosted low-code platforms, developer-friendly internal tool builders, and enterprise-grade model-driven frameworks—ideal for organizations building sovereign application infrastructure without per-seat or per-app licensing lock-in.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[ServiceNow Low-Code App Engine](https://www.servicenow.com/)**  
  Enterprise low-code platform on the Now Platform with App Engine Studio for visual app creation, Flow Designer for automation, and IntegrationHub for connecting external systems; enables departmental app development within ServiceNow's governed environment.

- **[OutSystems](https://www.outsystems.com/)**  
  Enterprise low-code platform emphasizing engineering discipline with version control, environment isolation, and DevOps pipeline integration; suited for organizations treating low-code as part of their formal software delivery lifecycle .

- **[Mendix](https://www.mendix.com/)**  
  Siemens-owned low-code platform with visual modeling, multi-channel deployment (web, mobile, native), and enterprise integration capabilities for building business-critical applications.

- **[Microsoft Power Apps](https://powerapps.microsoft.com/)**  
  Microsoft's low-code platform within the Power Platform ecosystem, with canvas apps for pixel-perfect design, model-driven apps for data-centric business processes, and deep integration with Microsoft 365, Dataverse, and Azure.

- **[Appian](https://www.appian.com/)**  
  Low-code automation platform with visual development, process mining, and AI capabilities for building enterprise applications and workflows.

- **[Quickbase](https://www.quickbase.com/)**  
  No-code/low-code platform for building business applications with database-driven apps, workflow automation, and enterprise governance features.

- **[Retool](https://retool.com/)**  
  Developer-focused low-code platform for building internal tools and admin panels; drag-and-drop components over 100+ integrations with SQL/API queries and JavaScript for custom logic.

- **[Zoho Creator](https://www.zoho.com/creator/)**  
  Low-code platform within the Zoho ecosystem for building business apps with visual builder, scripting (Deluge), and mobile app generation.

- **[Caspio](https://www.caspio.com/)**  
  No-code platform for building database-driven business applications with visual app builder and cloud database backend.

- **[Bubble](https://bubble.io/)**  
  No-code platform for building web applications with visual editor, database, and workflow logic; popular among startups and non-technical founders for MVP development.

## Open-Source GitHub Projects

- **[Appsmith](https://github.com/appsmithorg/appsmith)**  
  Leading open-source low-code platform for building internal tools and admin panels (Apache-2.0); drag-and-drop UI builder with JavaScript customization throughout, 25+ database integrations and any REST/GraphQL API, Git-based version control for apps, and self-hosted Docker/Kubernetes deployment; ~41k GitHub stars with active development and a clean Apache-2.0 license across the entire repository .

- **[ToolJet](https://github.com/ToolJet/ToolJet)**  
  Open-source low-code platform for internal tools with 80+ responsive components, a built-in ToolJet Database, 90+ data sources, and JavaScript/Python support within apps; AGPL-3.0 community edition with AI generation, workflows, and GitSync reserved for paid enterprise tiers; ~41k GitHub stars and Docker/Kubernetes deployment guides .

- **[Budibase](https://github.com/Budibase/budibase)**  
  Open-source low-code platform focused on operations workflows and request handling (GPL-3.0 core with BSL paid features); visual builder for forms, approvals, and ticketing apps, built-in automation agents, and unlimited users on the free self-hosted plan; ~28k GitHub stars, best suited for teams with lower technical barriers building workflow-driven apps .

- **[Convertigo](https://github.com/convertigo/convertigo)**  
  Enterprise-grade open-source AI-driven low-code and no-code platform (AGPL-3.0) from France; includes Convertigo Server (backend), Eclipse-based Studio for full-stack development, and No Code Studio for citizen developers; supports cross-platform mobile and web apps with offline sync, Docker/Helm deployment, and 150K+ developers worldwide .

- **[A12](https://github.com/a12-community/a12)**  
  German open-source model-driven low-code platform (EUPL 1.2) underpinning Germany's federal tax portal ELSTER and public sector OZG services; A12 Modelling Environment enables citizen developers to create business-logic modules, while the Runtime Platform supports secure on-premises deployment independent of hyperscalers; open-core model with free development/test and commercial production licensing .

- **[JeecgBoot](https://github.com/jeecgboot/JeecgBoot)**  
  Java-based low-code and no-code dual engine (~36k GitHub stars) with a very active Chinese community; covers admin panels, MIS, OA, ERP, and AI knowledge bases; a go-to choice for Java teams needing rapid enterprise application scaffolding .

- **[RuoYi](https://github.com/yangzongzhuan/RuoYi)**  
  Classic Java permissions scaffold with tens of thousands of GitHub stars; lightweight, easy to start, and a rock-solid base for admin systems with thorough documentation and tutorials; ideal for teams wanting a proven foundation rather than a full platform .

- **[NocoBase](https://github.com/nocobase/nocobase)**  
  Plugin-based no-code and low-code platform with strong self-hosting support and internationalization; suitable for lightweight data collaboration apps and internal tools where extensibility through plugins is valued .

### Additional Strong Open-Source Options

- **Oinone** — Metadata/model-driven development framework (~2.7k GitHub stars, AGPL-3.0) where AI and developers share one metadata model; built for complex business and deep enterprise customization with self-hosting and monolith-to-distributed flexibility .
- **Amis (Baidu)** — JSON configuration-based page builder from Baidu; a backend-UI assembly powerhouse with excellent documentation for frontend page generation .
- **Windmill** — Developer platform that turns scripts into workflows and UIs; an open-source alternative to Retool and Temporal with a fast workflow engine, self-hostable with PostgreSQL backend .
- **NocoDB** — Turns any database into a no-code spreadsheet interface; MIT-licensed and self-hostable for lightweight data applications .

**Frameworks for building custom systems**: Combine **Appsmith** for developer-led internal tools with Git versioning, **ToolJet** for multi-source tool pages with a built-in database, **Budibase** for workflow-driven approval and request apps, and **Convertigo** for enterprise mobile/web apps with backend orchestration in a self-hosted LCAP stack tailored to different builder skill levels and application types.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Low-code platforms handling business data must comply with applicable privacy regulations and organizational governance policies; audit logging and access controls are critical for production deployments.
- Self-hosted open-source solutions vary significantly in scope and licensing—Appsmith offers a fully permissive Apache-2.0 core, ToolJet and Budibase use open-core models with paid enterprise features, and enterprise platforms like A12 and Convertigo employ AGPL/EUPL licenses requiring compliance review for commercial use.
- Verify license terms for commercial use; Appsmith uses Apache-2.0, ToolJet uses AGPL-3.0, Budibase uses GPL-3.0 with BSL paid features, Convertigo uses AGPL-3.0, and A12 uses EUPL 1.2 .
